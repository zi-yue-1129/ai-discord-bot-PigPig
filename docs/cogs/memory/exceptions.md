# File: `cogs/memory/exceptions.py`

## Overview
This file is part of the `cogs` subsystem. It is responsible for `exceptions` related functionality within the PigPig system, contributing to Discord bot commands and feature logic.

## Classes

### `MemorySystemError`
Base exception for the memory system.

### `DatabaseError`
Related to database operations.

### `VectorOperationError`
Related to vector store operations like add or upsert.

### `SearchError`
Related to search or query operations in the vector store.

### `IndexIntegrityError`
Related to index creation or integrity in the vector store.

### `DiscordAPIError`
Related to errors when fetching data from the Discord API.
